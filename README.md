# Task Manager Application

A modern, full-stack task management application designed to help users efficiently organize, track, and prioritize their daily tasks and projects.

## Features
* **Task CRUD Operations:** Easily create, read, update, and delete tasks.
* **Status & Priority Tracking:** Organize tasks by priority levels (Low, Medium, High) and progress states (Pending, In Progress, Completed).
* **Responsive User Interface:** Clean, intuitive layout optimized for seamless use across different screen sizes and devices.
* **Data Persistence:** Reliable storage ensuring your lists and project updates are securely saved.
